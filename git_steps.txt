===================================================================
ขั้นตอนการอัปโหลดโค้ดขึ้น GitHub (Git Push) - Lab 10
Repository: https://github.com/kuroyukiina-del/Lab10.git
===================================================================

ข้อกำหนดสำคัญ:
- ห้ามนำไฟล์ `.env` และ `.env.local` ขึ้น Git (เพื่อความปลอดภัยของ Database Credentials)
- ห้ามนำโฟลเดอร์/ไฟล์ `app/api/debug-unsafe` ขึ้น Git

-------------------------------------------------------------------
ขั้นตอนที่ 1: ตรวจสอบและตั้งค่า .gitignore
-------------------------------------------------------------------
ตรวจสอบไฟล์ .gitignore ให้แน่ใจว่ามีรายการไฟล์ที่ไม่ต้องการอัปโหลด:

.env
.env.local
.env*.local
app/api/debug-unsafe
node_modules
.next

*(หากไฟล์ debug-unsafe เคยถูก track ใน Git มาก่อน ให้สั่งลบออกจาก Git Index ด้วยคำสั่ง:
git rm -r --cached app/api/debug-unsafe)*

-------------------------------------------------------------------
ขั้นตอนที่ 2: ตรวจสอบสถานะไฟล์ (Git Status)
-------------------------------------------------------------------
เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:

git status

ตรวจสอบว่าไม่มีไฟล์ .env หรือ debug-unsafe อยู่ในรายการที่จะถูก commit

-------------------------------------------------------------------
ขั้นตอนที่ 3: เพิ่มไฟล์ทั้งหมดเข้าสู่ Staging Area
-------------------------------------------------------------------
รันคำสั่ง:

git add .

-------------------------------------------------------------------
ขั้นตอนที่ 4: บันทึกการเปลี่ยนแปลง (Commit)
-------------------------------------------------------------------
รันคำสั่ง:

git commit -m "feat: complete Lab 10, remove debug-unsafe and exclude env"

-------------------------------------------------------------------
ขั้นตอนที่ 5: ตรวจสอบ Remote Repository
-------------------------------------------------------------------
ตรวจสอบว่า remote url ชี้ไปที่ Repository ที่ถูกต้องหรือไม่:

git remote -v

ถ้ายังไม่มี ให้เพิ่มด้วยคำสั่ง:
git remote add origin https://github.com/kuroyukiina-del/Lab10.git

-------------------------------------------------------------------
ขั้นตอนที่ 6: อัปโหลดขึ้น GitHub (Push)
-------------------------------------------------------------------
รันคำสั่ง:

git push origin main
(หรือ git push -u origin main ในกรณี push ครั้งแรก)
